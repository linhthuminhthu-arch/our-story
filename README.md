# Nghiệm Gần Đúng - A Mathematical Love Story

Một trang web tương tác kể câu chuyện tình yêu qua các phép ẩn dụ toán học đẹp đẽ và lãng mạn.

## Tổng quan

Website này mang câu chuyện về tình yêu được kể qua lăng kính toán học, với các khái niệm như:
- Nghiệm chính xác vs nghiệm gần đúng
- Phương pháp lặp và hội tụ
- Cực trị cục bộ vs cực trị toàn cục
- Gradient descent và optimization
- Hàm mất mát (loss function)

## Tính năng

- **Thiết kế responsive**: Tương thích với mọi thiết bị
- **Animation mượt mà**: Scroll-based reveals và transitions đẹp mắt
- **Visualizations toán học**: Biểu đồ tương tác minh họa các khái niệm
- **Background động**: Particles và equations floating
- **Easter egg**: Konami code để tạo hiệu ứng đặc biệt
- **Typography đẹp**: Phông chữ serif cổ điển

## Cách chạy

1. Mở terminal trong thư mục project
2. Chạy web server:
   ```bash
   python3 -m http.server 8000
   ```
3. Mở trình duyệt và truy cập: `http://localhost:8000`

## Cấu trúc project

```
├── index.html          # Cấu trúc HTML chính
├── styles.css          # Styling và animations
├── script.js           # JavaScript tương tác và visualizations
└── README.md           # Tài liệu này
```

## Các thư viện sử dụng

- **Chart.js**: Tạo biểu đồ toán học
- **Math.js**: Tính toán toán học
- **MathJax**: Hiển thị công thức toán học
- **CSS3 Animations**: Hiệu ứng và transitions
- **Intersection Observer API**: Scroll-based animations

## Câu chuyện

Website chia thành 6 phần chính:
1. **Khởi đầu với niềm tin** - Hàm số đơn giản
2. **Phương pháp lặp** - Iterative methods
3. **Hàm số phức tạp** - Local vs global optima
4. **Nhận ra** - Bài toán phi tuyến
5. **Cực trị địa phương** - Gradient descent
6. **Khởi đầu mới** - Convergence to love

## Thông điệp

Câu chuyện sử dụng các khái niệm toán học để diễn tả hành trình tình yêu:
- Từ nghiệm đơn giản đến bài toán phức tạp
- Từ cực trị cục bộ đến tìm kiếm nghiệm toàn cục
- Từ convergence nhanh đến patience và kiên nhẫn
- Cuối cùng là hàm tình yêu tiến tới vô cùng
